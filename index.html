Personal Google Apps Script Utility

Drive-Reconstruction

Drive-Reconstruction は、開発者個人の Google ドライブにおけるフォルダ階層管理、メタデータ構成ファイル（drive_manifest.json）の自動生成、アクセス権限ポリシーに応じたフォルダ色分け同期、および Google Apps Script ソースコードの Google ドキュメントバックアップを自動化する個人用ツールです。

Drive-Reconstruction is a private, single-user Google Workspace automation utility for managing personal Google Drive folder taxonomies, folder color coding, manifest generation, and automated Apps Script source backups to Google Docs.

プライバシーポリシー / Privacy Policy

主な機能 / Key Functionality

  • フォルダ階層の冪等構築: 個人用 Google ドライブ内の標準フォルダ構成（0x〜9x）を重複なく自動生成・維持します。
  • マニフェスト自動生成: 各フォルダの固有IDおよび運用ルールを drive_manifest.json として出力します。
  • 権限カラー自動同期: 定義されたアクセス区分に応じて、対象フォルダおよび配下フォルダの表示色を Drive API 経由で自動同期します。
  • ソースコード自動同期: 開発者本人が所有する Google Apps Script プロジェクトのソースコードを Apps Script API 経由で取得し、バックアップ用 Google ドキュメントへ自動反映します。

利用対象 / Target Audience

本アプリケーションは開発者本人の個人利用専用であり、第三者への一般提供や外部ユーザーのデータ収集・販売は一切行いません。

This application is strictly for the developer's personal use. It is not distributed to third-party users and does not collect, share, or sell external user data.
