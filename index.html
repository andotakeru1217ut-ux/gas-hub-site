Personal Google Apps Script Automation Hub

Personal GAS Hub

Personal GAS Hub は、開発者個人の Google Workspace 環境における複数の Google Apps Script（GAS）プロジェクトを統合管理・自動化するための個人用ユーティリティ基盤です。Google ドライブの構成管理、ソースコードの自動バックアップ同期、情報整理・スケジュール連携などの個人向け自動化ワークフローを安全に実行します。

Personal GAS Hub is a private, single-user Google Workspace automation hub that connects and manages the developer's personal Google Apps Script projects, including Google Drive structure management, automated source code backups, and personal productivity workflows.

プライバシーポリシー / Privacy Policy

主な機能領域 / Key Capabilities

  • Google ドライブ基盤管理: 標準フォルダ階層の冪等構築、構成マニフェスト（drive_manifest.json）の自動生成、およびアクセス区分に応じたフォルダ色分けの再帰同期を行います。
  • GAS ソースコード一元同期: 開発者本人が所有する複数の Google Apps Script プロジェクトのコードを Apps Script API 経由で取得し、バックアップ・参照用の Google ドキュメントへ自動同期します。
  • データ整理・自動ワークフロー連携: 開発者本人のアカウント内において、Google スプレッドシート・ドキュメント・カレンダー・Gmail 等と連携した定期集計、情報整理、および通知・ブリーフィング処理を自動化します。
  • 運用監査・保守の自動化: 定期トリガーによるファイル構成の整合性チェックや保守処理を実行し、個人データ基盤の健全性を維持します。

利用対象とポリシー / Target Audience & Policy

本アプリケーションは開発者本人の個人利用専用です。第三者ユーザーへの一般提供、外部サーバーへのデータ収集、またはユーザーデータの販売・広告利用は一切行いません。

This application is strictly restricted to the developer's personal use. It is not offered to third-party users and does not collect, sell, or share external user data.
