プライバシーポリシー / Privacy Policy

対象アプリ / Application: Drive-Reconstruction ｜ 最終改定日 / Last Updated: 2026-11-24

1. 概要 / Overview

本プライバシーポリシーは、個人用 Google Workspace 自動化ツール「Drive-Reconstruction」（以下「本アプリ」）における Google ユーザーデータの取り扱い方針を定めるものです。本アプリは開発者本人のアカウント内での自動化のみを目的としており、第三者ユーザーへの提供を行いません。

This Privacy Policy explains how Drive-Reconstruction ("the App") accesses, uses, stores, and protects Google user data. The App is built strictly for personal automation by its developer within their own Google account.

2. アクセスするデータと権限（OAuth スコープ） / Data Accessed

本アプリは以下の Google API スコープのみを使用し、必要最小限の操作を実行します。

OAuth スコープ / Scope 利用目的 / Purpose
https://www.googleapis.com/auth/drive Google ドライブ上のフォルダ構造の作成・参照、フォルダ色の更新、および構成ファイル（drive_manifest.json）の生成・更新。
https://www.googleapis.com/auth/documents ソースコードバックアップ用 Google ドキュメントの作成および更新。
https://www.googleapis.com/auth/script.projects.readonly 開発者本人が所有する Google Apps Script プロジェクトのソースコード一覧の読み取り専用取得。
https://www.googleapis.com/auth/script.external_request Apps Script API エンドポイントへの認証付き HTTP リクエスト送信。
https://www.googleapis.com/auth/script.scriptapp 定期メンテナンス用時間主導型トリガーの登録および実行管理。

3. データの利用・保存・保護 / Data Usage, Storage, and Protection

  • 本アプリはすべての処理を Google Apps Script 実行環境およびユーザー自身の Google ドライブ内で完結させます。
  • 外部サーバーへのユーザーデータ送信、第三者への提供・販売、広告目的での利用は一切行いません。
  • Google Workspace API を通じて取得したデータを、汎用的な AI/ML モデルの開発・改善・学習に使用することはありません。
  • 本アプリによる Google API から取得した情報の使用および他のアプリへの転送は、限定的な使用（Limited Use）の要件を含め、Google API Services User Data Policy を遵守します。

Drive-Reconstruction's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. We do not use Google Workspace API data to develop, improve, or train generalized AI/ML models.

4. データの保持とアクセス権の取り消し / Retention and Deletion

本アプリは外部データベースにデータを保存しません。Google アカウントの サードパーティ接続管理画面 から本アプリのアクセス権限をいつでも取り消すことができ、生成されたドライブ上のファイルはユーザー自身でいつでも削除可能です。

5. お問い合わせ / Contact

本プライバシーポリシーに関するお問い合わせは、Google Cloud コンソールの OAuth 同意画面（ブランディング設定）に登録された開発者連絡先メールアドレスまでご連絡ください。
