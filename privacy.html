プライバシーポリシー / Privacy Policy

対象アプリ / Application: Personal GAS Hub ｜ 最終改定日 / Last Updated: 2026-11-24

1. 概要 / Overview

本プライバシーポリシーは、個人用 Google Workspace 自動化基盤「Personal GAS Hub」（以下「本アプリ」）および本アプリに紐づく開発者個人の Google Apps Script プロジェクト群における Google ユーザーデータの取り扱い方針を定めるものです。本アプリは開発者本人の Google アカウント内での自動化のみを目的としており、第三者ユーザーへの提供を行いません。

This Privacy Policy explains how Personal GAS Hub ("the App") and its associated personal Google Apps Script projects access, use, store, and protect Google user data. The App operates exclusively within the developer's own Google account for personal automation.

2. アクセスするデータと権限（OAuth スコープ） / Data Accessed

本アプリは、各自動化スクリプトが必要とする最小限の Google API スコープ（最小権限の原則）のみを使用します。

3. データの利用・保存・保護 / Data Usage, Storage, and Protection

  • 本アプリはすべての処理を Google Apps Script 実行環境およびユーザー自身の Google Workspace（Google ドライブ・ドキュメント・スプレッドシート等）内で完結させます。
  • 第三者へのユーザーデータの提供、共有、販売、または広告・マーケティング目的での利用は一切行いません。
  • Google Workspace API を通じて取得したユーザーデータを、汎用的な AI/ML モデルの開発・改善・学習に使用することはありません。
  • 本アプリによる Google API から取得した情報の使用および他のアプリへの転送は、限定的な使用（Limited Use）の要件を含め、Google API Services User Data Policy を遵守します。

Personal GAS Hub's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google Workspace API data is never used to develop, improve, or train generalized AI/ML models.

4. データの保持とアクセス権の取り消し / Retention and Deletion

本アプリは開発者管理外の外部データベースに Google ユーザーデータを保持しません。ユーザーはいつでも Google アカウントの サードパーティ接続管理画面 から本アプリのアクセス権限を取り消すことができ、Google ドライブ上に生成されたすべてのファイルはユーザー自身で削除可能です。

5. プライバシーポリシーの変更 / Changes to This Policy

新たな個人用 GAS プロジェクトの連携等に伴い利用スコープや機能を追加・変更する場合は、本ページを随時更新します。

6. お問い合わせ / Contact

本プライバシーポリシーに関するお問い合わせは、Google Cloud コンソールの OAuth 同意画面（ブランディング設定）に登録された開発者連絡先メールアドレスまでご連絡ください。
